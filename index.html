Import course data

Go to the HKUST Class Schedule & Quota page (w5.ab.ust.hk/wcq), open a subject, select the whole page (Ctrl+A, Ctrl+C) and paste it below. Paste as many subjects as you like — repeat and click Parse each time.

How this works

  1. The catalog is already loaded. Every course in the term was scraped from w5.ab.ust.hk/wcq. To refresh it later, run node scripts/scrape.mjs. Import / Paste is there for anything the scrape missed.
  2. Pick your courses. Search, click to add. Expand a course to un-tick any section you can't or won't take (e.g. a lecture at 9am).
  3. Lock a section if you need one. Expand a course and set its Lecture or Tutorial picker from Any to a specific section — for slots you're pre-enrolled in, or a lecturer you want. Leave the other kind on Any to keep the choice open.
  4. Save the set. Once your courses are picked, name them under Saved groups and hit Save. Next time, one click restores the whole set — including any sections you un-ticked — so you never retype it.
  5. Set constraints, then hit Generate. Sorting by Best-rated professors ranks timetables using instructor grades from ust-rankings.com — nothing is filtered out. Star individual courses to weigh only those.
  6. Fill the gaps. Happy with a timetable but have room left? + Fill a gap lists courses — any course, or one Common Core group — that slot into your free time without moving anything you've already got.
  7. Browse every variant. The planner tries one section of each type (lecture + tutorial + lab) per course and keeps only combinations with zero clashes.

Linked sections: HKUST usually ties tutorial T1A and lab LA1 to lecture L1. That's enforced by default. If a course has shared tutorials across lectures, the planner detects it and relaxes the rule automatically for that course.

Nothing leaves your browser. Everything runs locally; your selection is saved to this browser only.
